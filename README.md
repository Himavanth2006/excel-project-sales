# Excel Project Sales Report Dashboard

## Overview
This project is an end-to-end sales analysis dashboard developed using Microsoft Excel. It provides insights into sales performance, customer demographics, order status, sales channels, and state-wise sales through an interactive dashboard.

## Objective
The objective of this project is to analyze sales data and present meaningful business insights to support data-driven decision-making.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions
- Dashboard Design

## Dashboard Features
- Orders vs Sales Analysis
- Sales by Men vs Women
- Order Status Analysis
- Top 5 States by Sales
- Orders by Age and Gender
- Sales by Channel

## Key Insights
- Women contributed a larger share of total sales than men.
- Most orders were successfully delivered.
- Maharashtra recorded the highest sales among all states.
- Adults placed the highest number of orders compared to teenagers and seniors.
- Amazon was the leading sales channel.
